# Commodore - Amiga (PUAE 2010)

### Description

UAE 2010 stands for the Ubiquitous Amiga Emulator based on the 2.6.1 source code branch.
The 2.6.1 branch is suited for low end devices with less CPU power.

Most games require a version of the Amiga Kickstart ROM. However, some old games will work with the built-in ROM emulation.
